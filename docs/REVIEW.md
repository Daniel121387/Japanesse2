### BUG-01 설정 화면이 매번 저장소에 씀 (중간)
- **재현**: 설정 화면을 열거나, 설정 화면에서 아무 위젯이나 조작
- **기대**: 값이 바뀔 때만 저장
- **실제**: `tts_slow`, `unlock_future`, `simulated_date`를 매 실행마다 저장. Supabase에서는 화면 갱신마다 쓰기 요청 3번
- **조치**: `pages/settings.py`에서 현재 값과 다를 때만 저장. 재검증: 잠금 해제 켜기 → 새로고침 후 유지 → 끄기 → 새로고침 후 꺼짐 확인

### BUG-02 Supabase 설정 읽기 요청 과다 (중간)
- **재현**: 코드 확인. 홈 한 번 그릴 때 `get_setting` 호출이 이름 3 + 글자 크기 + 시뮬레이션 + 잠금 등 5~10회이고, Supabase에서는 각각 네트워크 왕복
- **기대**: PRD 7장 "페이지 로딩 3초 이내"
- **실제**: 왕복 1회 100ms만 잡아도 0.5~1초가 추가됨
- **조치**: `SupabaseStorage`가 설정 표를 처음 한 번만 읽어 메모리에 두고, 저장할 때 같이 갱신(1인용 앱이라 어긋날 일 없음)
- **한계**: Supabase 계정이 없어 실제 연결로는 확인하지 못함

### BUG-03 헷갈리는 문장 복습 우선 미구현 (중간)
- **재현**: 복습에서 '헷갈려요' 표시 → 다음 복습 화면
- **기대**: PRD 6.3 "헷갈리는 문장은 다음 복습·테스트에 우선 출제"
- **실제**: 테스트에는 누적 출제되지만 복습은 주차별로만 볼 수 있음
- **조치**: 복습 주차 목록 맨 위에 "🤔 헷갈리는 문장 모음 (N개)" 덱 추가. 한 바퀴 도는 동안 카드 목록을 고정해서, '외웠어요'로 상태가 바뀌어도 카드가 건너뛰어지지 않게 함
- **재검증**: AppTest로 16개 덱에서 '외웠어요' 2번 → 위치 1/16 → 2/16 → 3/16, 목록 라벨은 남은 14개로 갱신

### BUG-04 휴대폰 제목 크기 역전 (낮음)
- **재현**: 360px에서 설정 화면. 제목 "설정"(25.6px)보다 소제목 "내 이름"이 더 큼 (3단계 스크린샷)
- **조치**: CSS로 h3를 19.2px(휴대폰) / 21.6px(그 외)로 지정. 재검증: h1 25.6px / h3 19.2px (`fix-settings-headings.png`)

### BUG-05 선택 상자 라벨 ✅ 갱신 지연 (낮음, 남김)
- **재현**: 오늘 화면에서 '학습 완료' → 닫힌 선택 상자에 해당 문장의 ✅가 안 보임
- **실제**: 펼친 목록에는 ✅가 모두 정상 표시. 화면 아래 "학습 완료 ✅" 안내도 바로 나옴
- **판단**: 학습 기록에는 영향 없고 Streamlit 위젯의 표시 갱신 문제라 남김

### BUG-07 PIN 재입력 (낮음, 남김)
- 로그인 상태를 세션에만 저장하므로 새로고침, 앱 휴면 후 재접속 시 PIN을 다시 입력해야 함
- 개선안: 쿠키에 PIN 해시를 저장하는 "이 기기 기억하기" 옵션 (아래 개선 제안 참고)

### BUG-08 여행 전 버튼 탭 위치 (낮음, 남김)
- 홈의 "오답 노트로 집중 복습" 버튼은 문장 화면을 열지만 첫 탭이 '전체 문장'이라 '오답 노트' 탭을 한 번 더 눌러야 함
- 개선안: 오답 노트를 별도 화면으로 분리하거나, 버튼 대상을 복습의 '헷갈리는 문장 모음'으로 변경

### BUG-09 콘솔 404 (정보)
- `http://localhost:8599/today` 처럼 하위 주소를 직접 열면 Streamlit 프런트엔드가 `/today/_stcore/health`를 먼저 찾다가 404 후 정상 경로로 재시도. 화면 동작에는 영향 없고, 직접 열 때 로딩이 1초 정도 늘어남(2.7초 vs 앱 안 이동 0.3~1.3초)

## 4. 데이터·시간대 검증

- 55문장: id 1~55 연속, 필수 필드 빈 값 없음, 일본어·뜻·한국어 발음 중복 없음, 날짜·요일·주차가 일정 로직과 일치
- 주차 메타데이터: 복습일·테스트일이 일정 로직과 일치
- 시간대: 한국 시간 자정 직후(00:30 KST = 전날 15:30 UTC)에 한국 날짜로 판정됨을 단위 테스트로 확인

## 5. 개선 제안

1. **배포 전 Supabase 연결 확인 (가장 중요)**: 무료 프로젝트 생성 → `docs/supabase.sql` 실행 → secrets 설정 → 휴대폰과 노트북에서 같은 진도가 보이는지 확인. SQLite로 배포하면 Streamlit Cloud가 재시작할 때 진도가 사라집니다(설정 화면에 현재 저장소 안내 추가함).
2. **PIN 기억하기**: 쿠키에 PIN 해시를 저장해 같은 기기에서는 다시 묻지 않기
3. **여행 모드 듣기 버튼 크게**(PRD 6.7): 목록 카드의 듣기 버튼을 전체 폭으로
4. **문장 조립 문제(P2)**: 여행 전 여유가 있으면 추가
5. **학습 알림**: Streamlit은 푸시 알림이 없으므로 휴대폰 캘린더에 평일 반복 알림 등록 권장
